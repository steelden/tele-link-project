# TeleLink

A desktop client for [MTS Link](https://mts-link.ru) chats, based on the source code of [Telegram Desktop](https://github.com/telegramdesktop/tdesktop): the fast and familiar interface of Telegram working with the MTS Link protocol.

The source code is published under GPLv3 with OpenSSL exception, the license is available [here][license].
